Start with your Spotify data

  1. Download the app. Save track-record.html somewhere you can find it, then double-click it to open it in your browser. The first screen walks you through importing your history.
  2. Request Extended streaming history. Visit Spotify’s account privacy page, request the extended history package and follow Spotify’s email instructions. This is separate from the basic account-data package. Your export may take time to prepare.
  3. Import your export. When it is ready, save Spotify’s ZIP in Downloads or a private folder. In Track Record, select the ZIP directly, or select the extracted Streaming_History_Audio_*.json and Streaming_History_Video_*.json files together.
  4. Keep a backup. Use Data & settings → Export backup. Browser storage for local files varies; moving the app or clearing browser data can affect it. You can always reimport your original ZIP or restore a backup.

No Spotify login is needed inside Track Record. Optional genre lookup contacts MusicBrainz only when you choose to run it. About Spotify’s data packages.
